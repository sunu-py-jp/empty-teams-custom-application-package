## 次に行うこと

1. `TeamsImportTest/manifest.json`の会社名、会社サイト・プライバシー・利用条件・タブのURL、`validDomains`を実際の情報へ変更します。
2. マニュアル6.6のチェックリストに従って再確認します。今回の会社情報の確定は初回配布準備として扱い、初回登録は`1.0.0`で構いません。既に登録した版を更新配布する場合はIDを維持して版を上げます。
3. マニュアル6.7の手順で、**`TeamsImportTest`の中の3ファイルだけ**をZIP化します。`TeamsImportVerification`全体や親フォルダーは圧縮対象にしません。
4. お客様の管理者が、登録前の利用範囲を確認してからマニュアル7章に沿って登録します。

現在の会社名マーカーは`要設定：開発会社の正式名称`、URLのホスト名は`example.invalid`です。このURLは作業用の未設定値であり、実際のページとして使用できません。
